# Bridge-owned recovery and authentication

The logical Codex turn owns saved native history, completed tool results and the
current tool capability. A browser conversation is a replaceable transport.
The model-progress watchdog and observed message-delivery failures can retire a
settled browser surface and continue from that saved input. Completed effects
are not invoked again. Consecutive recoveries without real model/tool progress
remain bounded; an unknown error, permission denial, explicit cancellation or
unsettled tool effect is not permission for a blind retry.

## Signed-out sessions

A visible anonymous composer does not prove authentication. The worker observes
rendered Login and Signup controls outside conversation messages, expired-session
alerts and the launcher's authentication-required release evidence.

On confirmed logout the bridge settles the old helper and preserves the logical
turn and its results. It enters a human-input wait, with its model watchdog and
compaction phase deadline suspended. The authenticated loopback control endpoint
`POST /v1/session/authentication` exposes only two booleans. The first
`{"required":true}` invalidates stale authentication evidence; subsequent `{}`
reads never navigate, send a prompt or spawn an inspection helper. Only the
existing verified user-login probe clears the requirement. Waiting is abortable,
and preserves the explicitly requested model and reasoning level.

The owner signs in using the launcher's normal Login flow. Once verified, the
bridge opens a fresh conversation with the latest native history and results.
It keeps the same native turn and tool capability. This is not a successful
completion until the actual task finishes. Zero Risk and non-launcher saved
sessions keep their explicit manual-authentication requirements.

## Fallback diagnosis

If an unknown internal fault still terminates the native turn, the managed
AI Swarm dispatcher queues a diagnostic callback to the owner and holds the
agent's ordinary queue. The owner must verify a real fix and any human action
before explicitly continuing the stopped turn. Authentication expiry cannot be
fixed by repeated generation requests. Callback receipts, heartbeat traffic and
an active process alone do not prove implementation or plan completion.
